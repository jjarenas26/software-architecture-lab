# Architecture Evaluation — Banking Case

Caso académico para practicar evaluación de arquitectura con **QAW + ATAM-lite**.

## Materiales

- [Caso del alumno](student-case.md)
- [Guía docente](teacher-guide.md)

## Objetivo

Pasar de afirmaciones vagas como:

> “La plataforma debe ser rápida y altamente disponible.”

a razonamiento arquitectónico verificable basado en:

- business drivers;
- quality attribute scenarios;
- utility tree;
- risks / non-risks;
- sensitivity points;
- trade-offs;
- risk themes.

## Nota metodológica

La actividad usa QAW de forma cercana a su propósito original y una **adaptación académica de ATAM**. Un ATAM formal requiere mayor duración, facilitación y participación de stakeholders.
